# Security policy

Please do not report security vulnerabilities in public issues, discussions or
pull requests.

Report them privately through GitHub's
[private vulnerability reporting](../../security/advisories/new) for this
repository. Include affected versions or commits, reproduction steps and the
impact you observed.

You should get an acknowledgement within a few days. Fixes are released as soon
as practical, and reporters are credited in the advisory unless they ask
otherwise.

Only the latest `main` is supported.
