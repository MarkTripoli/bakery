# Bakery logo

First concept, generated with the built-in image generation tool. Asset: `bakery-logo-v1.png`.

## Prompt

Use case: logo-brand.
Create a delightful, fun, cute, professionally designed logo for "bakery", a personal software factory where helpful agents build applications.

Make one finished horizontal logo lockup: an original compact mascot on the left, and the exact lowercase word "bakery" on the right. The mascot is a plump little golden bread-bun robot wearing a small soft chef's hat, with two simple dark eyes and a tiny friendly smile. Its silhouette should be recognizable at app-icon size. Express bakery warmth and a helpful little machine through a few clever shapes; keep the character simple and lovable rather than detailed or toy-like. Pair with a bespoke heavy rounded lowercase wordmark, softly irregular and full of personality, with beautifully balanced kerning.

Style: crisp flat vector-like brand artwork, smooth deliberate contours, generous negative space, very few shapes, restrained dark cocoa outlines, warm golden/apricot dough, buttercream chef's hat, and a tiny terracotta accent if helpful. The wordmark is solid dark cocoa. The mascot and wordmark must feel designed as one identity.

True transparent background with alpha, no backdrop, no shadows, no gradients, no 3D, no texture, no surrounding badge, no mockup, no slogan, no extra labels, no code snippets, no watermark. Keep generous clear space around the whole logo. Produce a single polished logo, not a board of variations.
