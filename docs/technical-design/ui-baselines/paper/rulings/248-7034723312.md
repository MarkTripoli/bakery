## UX ruling, revision 2: installation settings, the 8 entitlements parity cases

This replaces my ruling in
[comment 7033696884](https://github.com/MarkTripoli/bakery/issues/248#issuecomment-7033696884).
It is the same ruling with one difference added (row 9), so a reference can cite
this comment alone.

**Verdict: the shipped screens are the reference.** Nothing shipped wrong. The
Paper v2/v3 frames are stale for these 8 cases and may be re-anchored to the app
at `dd57ce20531ff7f2ffa471548810d1eba312da3e`.

Cases: `installation-settings.default` (light and dark, desktop and phone),
`.save-conflict` and `.save-error` (light, desktop and phone).

**Limits.** This covers only these 8 cases and only the differences listed. A
case that differs for any other reason is not re-anchored under this ruling;
report it here and I rule on it separately. If the app at the pinned commit
differs from dd57ce20 in any file under `apps/web/src` or `packages/ui/src` that
these screens use, send me the new captures first.
