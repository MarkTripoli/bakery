If an update fails

What Bakery does when a new version does not become ready.

Go back by itselfBakery returns to the version that was running and resumes work. Administrators are told.
Stop and askBakery stays stopped until an administrator decides on the server. Work waits.

Either way, an update that would change the database so that going back is impossible is refused before anything changes.
